1. Choose a review window

May 1 is an editable starting point based on the previously reviewed report ending in April—not a guarantee that earlier months are complete. Nothing is generated before an item's most recent historical occurrence.

2. Approve items to carry forward

Nothing is selected automatically. Confirm each item still applies. Amounts use the most recent transaction—not an average. A description can include multiple payments in a month; review frequency before proceeding.

Candidates must appear in at least two distinct months among the latest three recorded months within their finance scope. Only records before the review start are used to infer patterns. Generic rent, deposits, repairs, refunds and several other likely one-off descriptions are excluded from automatic suggestions. This can miss valid recurring items; it does not prove the ledger is complete.

3. Verify actual payments and expenses

For each item, check your records, enter the actual date and amount, then save it individually. Unconfirmed items do not affect cash-flow totals.

An existing transaction with the same scope, property, normalized description and month suppresses that suggestion, even when the amount differs. This intentionally avoids doubling up, but can hide partial payments. Review those in the ledger.
